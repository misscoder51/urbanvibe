🌆 UrbanVibe

UrbanVibe is a Gen-Z themed full-stack fashion e-commerce platform where users can browse categories, search for products, and view detailed product pages in a modern shopping interface.

🚀 Features

1. Category-based product browsing
2. Product search functionality
3. Detailed product pages
4. Responsive modern UI

🛠 Tech Stack

Frontend: React (Vite)
Backend: FastAPI
Database: SQLite
Deployment: Vercel (Frontend), Render (Backend)

⚙️ Run Locally
Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

Frontend
cd frontend
npm install
npm run dev
